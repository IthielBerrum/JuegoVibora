# Actividad 2 - Juego de la Víbora (Snake)

## Descripción

Este proyecto corresponde a la Actividad 2 de Herramientas Computacionales.

Se utilizó como base el juego Snake de la colección Free Python Games, desarrollada por Grant Jenks.

El objetivo de la actividad fue modificar el juego original utilizando Python y GitHub, trabajando mediante un esquema colaborativo Main/Fork.

## Modificaciones realizadas

Se realizaron las siguientes modificaciones al juego original:

1. La comida se mueve aleatoriamente un paso durante el juego.
2. La comida no puede salir de los límites del tablero.
3. El color de la serpiente se selecciona aleatoriamente.
4. El color de la comida también se selecciona aleatoriamente.
5. La serpiente y la comida utilizan colores diferentes.
6. Los colores se seleccionan entre cinco opciones disponibles.
7. El color rojo no se utiliza.

## Controles

- Flecha arriba: mover hacia arriba.
- Flecha abajo: mover hacia abajo.
- Flecha izquierda: mover hacia la izquierda.
- Flecha derecha: mover hacia la derecha.
